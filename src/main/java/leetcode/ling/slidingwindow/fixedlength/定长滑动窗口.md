### 定长滑动窗口模板

```java
public int slidingWindow(int[] nums, int k) {
    int n = nums.length;
    int ans = Integer.MIN_VALUE;
    int sum = 0;
    for (int i = 0; i < n; i++) {
        // 1. 入端点
        sum += nums[i];
        // 限制窗口左边界
        int left = i - k + 1;
        if (left < 0) continue;

        // 2. 计算
        ans = Math.max(ans, sum);

        // 3. 出端点
        sum -= nums[left];
    }
    return ans;
}
```
